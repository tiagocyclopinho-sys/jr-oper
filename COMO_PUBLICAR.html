📋 Etapas do Deploy
1

🗄️ Criar o Banco de Dados (Supabase)

Tempo estimado: 5 minutos · Custo: R$ 0,00 gratuito
›
📌 O QUE É ISSO?
É como criar uma planilha inteligente na nuvem que guarda todas as ocorrências, devoluções e dados do sistema. Qualquer aparelho que abrir o JR Oper vai ler e salvar nessa planilha online.
1
Acesse o Supabase

Abra supabase.com e clique em "Sign In". Entre com a conta que você já tem.

2
Crie um novo projeto

Clique em "New Project". Preencha assim:
• Nome: JR-Oper
• Senha do banco: crie uma senha forte (anote!)
• Região: escolha South America (São Paulo)
Clique em "Create new project" e aguarde ~2 minutos.

3
Abra o Editor SQL

No menu esquerdo do Supabase, clique em "SQL Editor" (ícone de banco de dados). Depois clique em "New query".

4
Execute o Schema (cria as tabelas)

Abra o arquivo database/schema.sql da pasta do projeto com o Bloco de Notas. Selecione tudo (Ctrl+A), copie (Ctrl+C) e cole no editor do Supabase. Clique no botão verde "Run".

✅ O QUE DEVE APARECER
"Success. No rows returned" — Isso é certo! Significa que as tabelas foram criadas.
5
Execute os dados iniciais dos setores

Abra uma nova query no Supabase. Abra o arquivo database/export_data.sql, copie e cole. Clique em "Run". Isso carrega os setores (SAC, CD, Financeiro, Frota) e usuários iniciais.

2

🔑 Pegar as Chaves de Acesso do Supabase

Tempo estimado: 2 minutos · Você vai copiar 2 informações
›
📌 O QUE SÃO AS CHAVES?
São como uma senha especial que autoriza o JR Oper a se conectar ao banco de dados. São 2 informações: a URL (endereço) e a chave anon (senha pública).
1
Vá nas Configurações do Projeto

No Supabase, no menu esquerdo, clique em "Project Settings" (ícone de engrenagem ⚙️ no rodapé do menu).

2
Clique em "API"

No submenu que aparece, clique em "API". Você verá duas informações importantes.

3
Copie a URL do Projeto

Na seção "Project URL", clique no ícone de copiar ao lado do endereço que começa com https://. Cole em um bloco de notas.

Exemplo de URL (a sua será diferente):
https://abcdefgh.supabase.co
4
Copie a Chave anon public

Na seção "Project API keys", copie a chave chamada anon / public. É uma sequência longa começando com eyJ.... Cole no bloco de notas junto com a URL.

⚠️ IMPORTANTE
Copie a chave anon public, NÃO a service_role. A anon é a chave segura para uso público.
3

🐙 Enviar o Código para o GitHub

Tempo estimado: 4 minutos · Faz isso uma vez só
›
📌 POR QUE O GITHUB?
O Vercel (que publica o site) precisa que o código esteja no GitHub. É como colocar os arquivos em uma pasta online para o Vercel conseguir ler.
1
Acesse o GitHub

Abra github.com e entre com sua conta.

2
Crie um novo repositório

Clique no botão "+" no topo direito → "New repository". Preencha:
• Repository name: jr-oper
• Visibilidade: Private (privado)
Clique em "Create repository".

3
Faça o upload dos arquivos

Na página do repositório vazio, clique em "uploading an existing file". Arraste toda a pasta jr-sac-corrigido para a área de upload. Aguarde o upload e clique em "Commit changes".

⚠️ ATENÇÃO
Arraste o CONTEÚDO da pasta (os arquivos index.html, js/, etc.), não a pasta em si.
1
Abra o Terminal/PowerShell na pasta do projeto

Clique com botão direito dentro da pasta jr-sac-corrigido → "Abrir no Terminal".

2
Execute os comandos
git init
git add .
git commit -m "JR Oper - Deploy inicial"
git remote add origin https://github.com/SEU-USUARIO/jr-oper.git
git push -u origin main
4

🌐 Publicar o JR Oper na Internet (Vercel)

Tempo estimado: 3 minutos · Resultado: link público do sistema
›
📌 O QUE O VERCEL FAZ?
Pega o código do GitHub e transforma em um site online com um endereço (URL) que qualquer um pode acessar. É automático: toda vez que você atualizar o código, o site atualiza sozinho.
1
Acesse o Vercel

Abra vercel.com e clique em "Log in". Entre com "Continue with GitHub" para vincular as duas contas.

2
Adicione um novo projeto

No painel do Vercel, clique em "Add New → Project". O Vercel vai listar os repositórios do seu GitHub. Clique em "Import" ao lado do repositório jr-oper.

3
Configure e publique

Na tela de configuração do projeto:
• Framework Preset: deixe em "Other"
• Root Directory: deixe vazio
Clique em "Deploy". Aguarde cerca de 30 segundos.

4
🎉 Seu link está pronto!

O Vercel vai mostrar um link como jr-oper.vercel.app. Este é o endereço do JR Oper para toda a empresa! Copie e salve esse link.

💡 DICA: Domínio personalizado
O Vercel permite usar um domínio próprio (ex: jroper.jrdistribuidora.com.br) gratuitamente. Isso pode ser configurado depois em Settings → Domains.
5

🔌 Conectar ao Banco e Instalar nos Aparelhos

Tempo estimado: 3 minutos · Faz em cada aparelho da empresa
›
📌 COMO FUNCIONA
Após publicar o site no Vercel, você abre o JR Oper pelo link e usa o botão "☁️ Configurar Nuvem" no rodapé para colar as chaves do Supabase. Sem precisar editar nenhum arquivo.
1
Abra o link do JR Oper

No computador principal (o seu), acesse o link gerado pelo Vercel (ex: jr-oper.vercel.app).

2
Clique em "☁️ Configurar Nuvem"

No rodapé do JR Oper, você verá o botão "☁️ Configurar Nuvem". Clique nele.

3
Cole a URL e a Chave

No painel que abrir, cole:
• No campo URL: o endereço do Supabase (https://xxx.supabase.co)
• No campo Chave: a chave anon public (eyJ...)

4
Clique em "🔌 Testar Conexão" e depois "💾 Salvar e Ativar"

Se aparecer ✅, está conectado! O indicador no rodapé mudará para 🟢 Nuvem Ativa. Repita esse processo em cada aparelho da empresa.

1
Abra o link no Chrome

2
Instale o app

O Chrome mostrará um banner na parte de baixo da tela: "Adicionar JR Oper à tela inicial". Toque nele. Se não aparecer, toque nos 3 pontinhos (⋮) no canto superior direito → "Adicionar à tela inicial".

Pronto!

O ícone do JR Oper aparecerá na tela inicial do celular. Toque nele para abrir como um aplicativo normal, sem a barra do navegador.

1
Abra o link no Safari

2

Toque no ícone de compartilhar (um quadrado com seta para cima ⬆) na barra inferior do Safari.

3
Adicionar à Tela de Início

Role a lista de opções para baixo e toque em "Adicionar à Tela de Início". Confirme com "Adicionar".

Pronto!

O JR Oper aparece como app na tela inicial. Abre sem barra do Safari, como um app nativo.

Abra o link no Chrome ou Edge

No computador, acesse o link do Vercel pelo Google Chrome ou Microsoft Edge.

2
Instale o app

Na barra de endereço do Chrome/Edge, aparecerá um ícone de instalar (computador com seta ↓) no lado direito. Clique nele → "Instalar". O JR Oper abre numa janela própria, sem abas do navegador.

Atalho na área de trabalho

O sistema cria automaticamente um atalho na área de trabalho. Basta dar dois cliques para abrir o JR Oper como se fosse um programa instalado.

❓ Dúvidas frequentes
🔒 Os dados são seguros?
Sim. O Supabase usa criptografia HTTPS/TLS em todas as conexões (o cadeado verde que aparece no navegador). Os dados ficam em servidores da AWS em São Paulo. Somente quem tiver o link do sistema e as chaves configuradas consegue acessar.
💸 Quando começa a cobrar?
O plano gratuito do Supabase suporta até 500MB de banco de dados e 2GB de tráfego por mês. Para o JR Oper de uma distribuidora, isso é mais do que suficiente por anos. O Vercel gratuito suporta 100GB de tráfego por mês. Só pagaria se o sistema crescer muito além do normal.
📴 E se a internet cair no trabalho?
O JR Oper foi configurado para funcionar offline. Se a internet cair, o sistema continua funcionando com os dados salvos localmente. Quando a internet voltar, tudo é sincronizado automaticamente com o banco de dados.
🔄 Como atualizar o sistema depois?
Basta fazer upload dos arquivos atualizados no GitHub. O Vercel detecta automaticamente e publica a nova versão em menos de 1 minuto. Todos os usuários receberão a atualização na próxima vez que abrirem o app.
🏫 A versão de treinamento fica separada?
Sim. A versão de treinamento é a pasta local no seu computador, aberta diretamente pelo arquivo index.html. Ela usa o modo "local" e não se conecta a nenhum banco. A versão de produção é o link do Vercel. São completamente independentes.
